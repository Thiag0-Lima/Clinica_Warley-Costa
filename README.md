# Clínica Warley Costa

Proposta de site institucional para a Clínica Warley Costa, com informações sobre procedimentos, depoimentos, localização e contato.

## Tecnologias

- HTML
- CSS
- JavaScript

## Executar localmente

Abra `index.html` em um navegador.

## GitHub Pages

No repositório, acesse **Settings → Pages** e publique a branch `main`, usando a pasta `/ (root)`.
